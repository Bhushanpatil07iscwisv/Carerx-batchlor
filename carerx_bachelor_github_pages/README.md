# CareRx Bachelor — Urgent Tele-Consult & Smart e-Prescription

An affordable urgent tele-consultation, multi-illness safety check, and generic medicine e-Prescription web app designed for students, hostelers, and working bachelors.

## Key Features
- **Patient Booking & AI Symptom Pre-Checker**: Log multiple active symptoms, co-existing bachelor health conditions (such as gastritis or asthma), vitals, and drug allergies for a ₹49 urgent consultation.
- **Mandatory Doctor Multi-Illness Verification**: Requires the doctor to examine and verify every reported patient illness before issuing a prescription, with automatic drug-allergy and contraindication blocks.
- **Digital e-Prescription (e-Rx) & Generic Price Mapper**: Generates a printable, QR-verified prescription comparing branded prices against Jan Aushadhi generic equivalents (saving up to 75%).
- **Live UPI QR Payment Gateway**: Dynamically generates a scannable UPI QR code (`9834422118@yespop`) that initiates the exact Rupee payment when scanned with Google Pay, PhonePe, Paytm, or BHIM.

## Quick Deploy to GitHub Pages
1. Create a new public repository on [GitHub](https://github.com/new) named `carerx-bachelor`.
2. Upload the contents of this folder (`index.html`, `README.md`, `.nojekyll`, and `.github/workflows/deploy.yml`).
3. Go to **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions** (or **Deploy from a branch → `main` / `/ (root)`**).
4. Your live site will be published at `https://<your-github-username>.github.io/carerx-bachelor/`.
